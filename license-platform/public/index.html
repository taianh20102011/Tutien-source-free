Mapping hiệu ứng

effects:
  itemsadder:
    enabled: true
    map: {}

Cách dùng: merge phần map vào file plugins/TuTienPlugin/config.yml, không ghi đè toàn bộ config đang chạy. Premium build cần license PREMIUM còn hiệu lực để phát hiệu ứng skin tùy chỉnh.
